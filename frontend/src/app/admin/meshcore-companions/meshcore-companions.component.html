Position, dernier contact, sauts et région dès que connus, synchronisés régulièrement par le service-pont. Une ligne sans position (ex: room server sans module GPS) peut ne jamais afficher de coordonnées, ça reste normal — le nombre de sauts reste vide (« — ») tant qu'aucun message n'a encore été routé via ce nœud (le firmware ne le connaît qu'après un chemin réellement confirmé, pas juste une annonce reçue directement) ; la région, elle, n'est jamais devinée automatiquement — c'est une étiquette libre à poser à la main ci-dessous.
